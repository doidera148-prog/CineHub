## Default Permission

Permite abrir o player nativo do Android

#### This default permission set includes the following:

- `allow-play`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>

</td>
<td>

</td>
</tr>

<tr>

</td>
